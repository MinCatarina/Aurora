## 📋 Sobre o projeto

A **Aurora** é uma landing page para uma plataforma fictícia de *People Analytics*: ela ajuda
times de RH a entender, engajar e reter talentos usando dados e inteligência artificial.

Este repositório reúne a entrega da **Etapa 2** do desafio **People First Cup: Enterprise
Challenge**, evoluindo o protótipo definido na Etapa 1 para uma landing page publicada,
responsiva e com formulário de captação de lead realmente funcional.

## ✨ Funcionalidades

- 🎯 Página única com proposta de valor, benefícios, planos, depoimentos e FAQ
- 📩 Formulário de captação de lead com validação e envio real (Netlify Forms)
- 📱 Layout 100% responsivo, do celular ao desktop
- ♿ Recursos de acessibilidade implementados e documentados na própria página
- 🎨 Identidade visual em gradiente violeta/azul, com tipografia Outfit
